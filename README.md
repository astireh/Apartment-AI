# 🏢 КвартираИИ — ИИ-агент по подбору квартир (ГК ДСК)

> 🟠 **Новый сервис на базе ИИ • Воронеж**

### 🤖 Квартира для покупки найдётся сама

**AI-агент для автоматизированного подбора квартир в жилых комплексах ГК «ДСК».**

Агент понимает запросы пользователя на естественном языке, уточняет недостающие параметры, подбирает квартиры, позволяет выбирать и сравнивать ЖК и квартиры, получать дополнительную информацию и бронировать подходящие варианты.


### 💬 Как это выглядит в чате

![Пример работы чата](docs/skrin.png)


## ✨ Возможности

1. Поиск квартир по параметрам: количество комнат, цена, площадь, этаж
2. Уточнение недостающих параметров
3. Изменение параметров поиска в ходе диалога
4. Поиск ближайших альтернатив
5. Подбор и выбор жилых комплексов
6. Сравнение ЖК
7. Выбор и сравнение квартир
8. Получение информации о квартирах и ЖК
9. Рекомендации наиболее подходящих вариантов
10. Бронирование квартиры на 3 часа бесплатно или на 1 месяц за 20 000 ₽
11. Автоматическое освобождение квартиры после окончания бронирования
12. Передача запроса менеджеру
13. Сохранение контекста диалога в рамках пользовательской сессии

## 🚀 Установка

**1. Клонируйте репозиторий:**
```bash
git clone <ССЫЛКА_НА_РЕПОЗИТОРИЙ>
cd dsk-ai-agent/backend
```

**2. Создайте виртуальное окружение (Windows):**
```bash
python -m venv venv
venv\Scripts\activate
```

> ⚠️ **Если PowerShell выдаёт ошибку** `выполнение сценариев отключено в этой системе` — выполните перед активацией:
> ```bash
> Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
> ```
> Это разрешает запуск скриптов только в текущем окне терминала, безопасно.

**3. Установите зависимости:**
```bash
pip install -r requirements.txt
```

**4. Настройте $\color{#F2941E}{\textsf{GigaChat}}$:**
Создайте файл `.env` в папке `backend/` по образцу `.env.example`:
```env
GIGACHAT_CREDENTIALS=ваши_credentials
```
Credentials можно получить бесплатно на [портале GigaChat API](https://developers.sber.ru/portal/products/gigachat) — понадобится регистрация и создание проекта в личном кабинете.

## 🏃‍♂️ Запуск

**1. Запустите $\color{#12233F}{\textsf{backend}}$** (из папки `backend/`, при активном venv):
```bash
uvicorn api:app --reload
```
> API будет доступно на `http://127.0.0.1:8000`, Swagger-документация — на `http://127.0.0.1:8000/docs`.
>
> $\color{#12233F}{\textsf{Backend}}$ уже настроен разрешать запросы с $\color{#12233F}{\textsf{фронтенда}}$ (CORS включён), дополнительная настройка не требуется.

**2. Откройте `frontend/index.html` двойным кликом в браузере** — сервер должен продолжать работать в терминале. Чат на странице сразу начнёт обращаться к запущенному $\color{#12233F}{\textsf{backend}}$, никаких дополнительных действий не нужно.

## 🔌 API

**GET `/health`** — проверка работоспособности $\color{#12233F}{\textsf{backend}}$.

**POST `/chat`** — основной эндпоинт для взаимодействия с агентом.

```json
{
  "session_id": "user-123",
  "message": "Покажи двушки до 15 миллионов"
}
```

> ⚠️ **Важно:** `session_id` должен оставаться одинаковым в рамках одного диалога пользователя.

**Типы ответов (поле `type`):**
`search`, `alternative`, `clarification`, `selection`, `information`, `comparison`, `booking`, `payment`, `manager`, `error`.
